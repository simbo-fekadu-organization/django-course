# Django Course: Build a Student Registration System

In this course, students will build a complete Student Registration System with Django, covering models, database operations, the admin panel, ORM queries, views, URLs, templates, and full CRUD functionality in the browser.

| Lesson | Description |
|--------|-------------|
| [00-setup](./00-setup) | Project setup and initialization |
| [01-models-database](./01-models-database) | Creating models and database schema |
| [02-admin-panel](./02-admin-panel) | Configuring the Django admin interface |
| [03-orm-crud-shell](./03-orm-crud-shell) | ORM operations in the Django shell |
| [04-views-urls](./04-views-urls) | Building views and URL routing |
| [05-templates](./05-templates) | Creating HTML templates |
| [06-crud-in-browser](./06-crud-in-browser) | Full CRUD functionality in the browser |
